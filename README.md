## 為什麼是 Claude

試過各家，最後留在 [Claude](https://claude.ai)。沒什麼信仰，純粹是順手，就像用慣的鍵盤，不見得最好，但換了會不習慣。

我的開發流程大概是：

- **技術選型**：丟給 Claude 分析 trade-off，我負責做決定。（通常跟它的建議一樣，但按下 Enter 的是我。）
- **架構**：我用自然語言描述，它出骨架，我審核。有時候審到一半發現是我自己沒講清楚。
- **Debug**：直接貼 stack trace，省下來的時間拿去喝咖啡。咖啡喝完，bug 也修好了。
- **最花心思的地方**：把需求講清楚。這件事以前叫「寫 spec」，現在叫「prompt engineering」，差別是這次對方不會抱怨需求又改了。
